▸ About this app read this first
What it is
A reference app that answers seven questions about more than 150 years of men's international football, and runs the same container images on Azure Kubernetes Service (AKS) and Azure Container Apps (ACA).
How it works
The web service renders these pages. The internal insights service holds deterministic analytics tools over a curated copy of the data and an AI agent. An ingest job verifies the raw downloads and builds that curated copy.
What is deterministic and what is AI
Every number, chart, and table comes from tested analytics code. A Microsoft Foundry model reads your question, picks tools, and explains their results in words. A grounding check rejects any number the model writes that the tools did not return.
Where the data came from
Two public Kaggle datasets (see the footer). The repository contains no data: you download it yourself. Coverage and quirks are on the Data page.
